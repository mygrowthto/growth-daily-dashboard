TEST DESIGN

从分层话术，到规范的 A/B 测试

真实触达中，开场话术按用户互动行为分层——关注 / 点赞 / 评论 / 收藏医生大号，各用不同的开场。 A/B 比较必须发生在同一分层内，否则「人群差异」会混进「版本差异」，结论就不可信。

分层维度
互动行为：关注 / 点赞 / 评论 / 收藏
当前分组
按日期：A 版 2 天、B 版 1 天，非随机分流
主指标
回复率 = 回复数 / 触达数
护栏指标
微信转化率、账号异常 / 限流
规范做法
固定素材与入口 → 层内随机分流 → 预设样本量 → 观察 7–14 天
结论边界
只能提示方向，不能声称因果或「显著提升」

METHOD & LIMITS

指标口径与边界

数据来源：内部日报（已脱敏）

01

回复率

回复数 / 触达数

衡量触达后得到反馈的效率，不直接等于加微信效率。

02

微信转化率

(主动微信 + 被动微信) / 触达数

只看原始计数重算，不复制表格里可能不一致的百分比。

03

播放 / 触达指数

当日值 / 首日值 × 100

用于比较两个不同量级指标的变化方向，不能替代绝对值。

04

A/B 测试（观察性）

Σ回复数 / Σ触达数

按实际触达加权；按日期分组不等于随机分流，只能作为方向性复盘。
