# 实现说明

本文件记录工作台的实现结构与验证方式，对应 `README.md` 的设计决策。

## 原则

- 仅使用已脱敏的 3 天样例数据。
- 指标百分比由代码统一计算，不复制原表数值。
- 先固化测试期望，再实现计算函数。
- 不依赖在线 CDN，作品可离线运行。
- 不实现登录、后端、数据库，也不做未经证实的显著性推断。

## 模块划分

| 模块 | 职责 |
|---|---|
| `data/daily-data.json` | 3 天原始计数与口径元数据 |
| `src/metrics.js` | 比例、指数、漏斗、预警计算与边界处理 |
| `src/charts.js` | 原生 SVG 趋势图与转化漏斗 |
| `src/app.js` | 读取数据、渲染 KPI / 表格 / 章节、日期切换 |
| `index.html` + `assets/styles.css` | 页面结构与响应式视觉 |
| `scripts/serve.mjs` | Node 内置模块的零依赖静态服务器 |
| `tests/` | 指标、数据、图表、服务器行为的自动化测试 |

## 实现顺序

1. 建立指标公式与 `safeRatio` 边界处理，测试覆盖分母为 0 与非数值。
2. 定义日报数据结构，测试校验天数、字段类型与 8 月 1 日基准值。
3. 实现漏斗与趋势图几何，测试校验折线端点、日期标签与图例。
4. 实现页面渲染：KPI、环比与百分点格式（比例环比用 `pp` 避免歧义）、异常预警、日报明细表。
5. 实现静态服务器：仅 GET / HEAD、路径穿越防护、`Cache-Control: no-store`。
6. 补齐 `npm test` / `npm start` / `npm run check` 命令与响应式验收。

## 验证

- `node --test`：24 个测试通过，覆盖计算、数据完整性、SVG 几何与 HTTP 行为。
- `node --check`：4 个模块语法通过。
- 桌面 1440×900 与手机 390×844：无横向溢出、日期切换正常、控制台无 error。
- 8 月 1 日转化率重算 4.3% → 6.3%；8 月 2 日播放 +62.3% / 触达 +27.7% 触发承接预警。
- 静态服务：`GET /` 与 `GET /data/daily-data.json` 为 200，其他方法 405，未知路径 404。

## 已知边界

3 天样例、话术版本未随机分组、微信转化数与回复数可能存在口径重叠，页面均已标注；详见 `README.md`「数据边界与局限」与 `review.md`。
